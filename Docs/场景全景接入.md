# 余音 · 场景全景接入

## 一、正式背景

- 源图：`Assets/Art/Scene/YuyinPanorama.png`
- 已裁掉原图上下黑边，有效内容为 `1670 × 540`。
- 导入：Sprite、Single、PPU 100、中心枢轴、Bilinear、无 Mipmap、Uncompressed。
- 场景里的物体名为 `PanoramaBackdrop`，由 `PanoramaBackdropView` 管理。
- 普通场景按楼层/后院取景；NPC 行动拼接时只保留一份 `38.4` 世界宽的全景，拆场景后恢复。

## 二、统一锚点

所有坐标集中在 `Assets/Scripts/Config/SceneLayoutMetrics.cs`，不要在各场景脚本里另写一套。

| 项目 | 坐标 |
| --- | ---: |
| 老婆婆门 | x = -5.37 |
| 大叔门 | x = 3.32 |
| 母亲二楼门 | x = -5.78 |
| 小女孩二楼门 | x = 6.75 |
| 一楼/二楼楼梯传送点 | x = 8.45 |
| 全景水平范围 | -9.6 ~ 28.8 |
| 地板线 | y = -3.4 |
| 主角 transform | y = -3.0（立绘底边落在 -3.5） |

小女孩的 `homeArea = SecondFloor`；一楼只保留老婆婆、大叔，二楼保留母亲、小女孩，后院保留三人的外出副本。

## 三、旧表现层

墙、地板、楼梯、门框、门叶和传送点色块会在运行时隐藏，只保留逻辑对象、碰撞与交互：

- `Door_*`、`Portal_*`、`Stair_*` 继续用于门位提示和场景切换。
- `Roof` 对象保留，雨丝屋顶排除逻辑继续使用。
- 母亲门的 `DoorLightView` 与 `Seam Light` 保留，门色块本身隐藏。

## 四、重跑布局

菜单：`Tools → 余音 → 套用全景背景与场景锚点`

批处理：

```powershell
& "<Unity>\Editor\Unity.exe" -batchmode `
  -projectPath "E:\unity\咕咕嘎嘎" `
  -executeMethod YuyinSceneLayoutTool.ApplyFromCommandLine `
  -logFile "E:\unity\咕咕嘎嘎\Logs\panorama-layout.log"
```

工具是幂等的，不会重建物品、UI、角色美术配置或会话数据。
