# 余音 · 数值结算系统 + 玩家控制与交互

## 一、数值结算系统（StatSettlement）

`Assets/Scripts/Core/StatSettlement.cs` 是**全局唯一做暖意 / 知晓度加减法的地方**。
物品系统、NPC 行为、玩家交互都只调用它，自己不算数。

### 所有加减法

| 事件 | 方法 | 暖意 | 知晓度 |
| --- | --- | --- | --- |
| 拿到有温度的东西 | `ApplyItemTaken(by, true)` | +18 | +15 |
| 拿到没温度的东西 | `ApplyItemTaken(by, false)` | +0 | +15 |
| 普通交流 | `ApplyTalk(target, false)` | +4 | +8 |
| 交流母亲 | `ApplyTalk(Mother, false)` | **+0（固定 30）** | +11 |
| 小女孩移动东西 | `ApplyGirlMovedItem(item)` | +18（并把物品温度清零） | — |
| 强行触碰 | `ApplyForceTouch(resident)` | −8 | — |
| 强碰传染 | `ApplyForceTouchContagion(target)` / `ApplyTalk(target, true)` | −5（母亲不受影响） | +8（对母亲 +11） |
| 母亲开门（**第 6 轮结束后才判**） | `ResolveMotherDoorAtEnd()` | 跳到 61（只变这一次） | — |

> 交流的数值加在**被交流的一方**（文档写「输出：目标住户的知晓度」）；
> 被强碰者自己那次交流不加暖意、知晓也不变。

### 阈值集中在这里

| 阈值 | 值 | 方法 |
| --- | --- | --- |
| 门缝 / 半开 | 30 / 55 | `ResolveDoorSeam(warmth)` |
| 门缝光 白 / 浅黄 / 橙 | 30 / 54 | `ResolveLightTint(awareness, hasAwareness)` |
| 高 / 低档位 | 60（严格大于） | `IsHigh(value)` |
| 母亲开门 | 60（严格大于） | `IsMotherOpen(awareness)` |
| 母亲开门后 | 暖意 61 | `ResolveMotherDoorAtEnd()` + `ItemSystem.CollectMotherItems()` |

> **母亲的暖意只有 30 和 61 两个值**：整局固定 30（不会被强碰传染扣），
> 只有第 6 轮结束后判定开门时才跳到 61，并**一次性收走自己所有东西**。

数值本身的上下限（0~100）与事件广播仍然由 `GameSession.AddWarmth / AddAwareness` 负责。

## 二、玩家控制与交互

`Assets/Scripts/Views/PlayerController.cs` + `Core/ItemSystem.cs`。

| 要求 | 实现 |
| --- | --- |
| 移动键 | `Horizontal` 轴，只沿 X 移动；`GameFlow.CanPlayerMove` 为 false 时不动（NPC 行动阶段 / 暂停 / 结束） |
| 触碰检测 | `E` 键 → 遍历本场景 `ItemView`，**只比左右距离**（`interactRadius=0.8`），**高度不限制**（晾衣架上的衣服站着也能碰） |
| 可交互提示 | 靠近可碰物品 → 屏幕下方出现「按 E 触碰」；离开 / 不可交互时隐藏（`InteractHintEvent` + `PromptOverlay`） |
| 二次触碰提示 | 已有温度 → `ItemActionStatus.AlreadyTouched` + `ItemPromptEvent { "你已经触摸过了。" }` |
| 未找到物品仍可行动 | 没命中物品时不消耗本轮触碰、不产生任何效果，玩家可以继续移动 / 再按 E |
| 强碰前 2 次只警告 | `session.forceTouchWarningsUsed < forceTouchWarnCount(2)` → 只发 `ForceTouchWarnedEvent`，**不消耗本轮触碰** |
| 第 3 次起生效 | 物品获得温度 + 该住户进入「惊吓」+ 暖意 −8，并解除区域占用；消耗本轮触碰 |
| 碰母亲物品给疑惑 | `ApplyConfusion()` → 30% 概率 2 人、否则 1 人，随机给老婆婆 / 大叔 / 小女孩 `NpcState.Confused` |

### 提示怎么显示

`Assets/Scripts/Views/PromptOverlay.cs`（`GameRoot` 自动挂）订阅
`ItemPromptEvent` / `ForceTouchWarnedEvent`，把文字画在屏幕下方约 2 秒 ——
不需要 Canvas / Prefab，正式 UI 接进来后可以删掉。
