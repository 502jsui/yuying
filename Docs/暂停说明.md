# 余音 · 暂停

## 一、怎么做的

**暂停 = 跳到独立的暂停场景**，游戏场景整个卸载掉；暂停场景的背景就是"点暂停那一刻的游戏画面截图"。

```
游戏里按 ESC（或 UI 的暂停按钮）
  → 等这一帧画完，截一张画面（PauseSnapshot）
  → GameFlow.Pause()：Time.timeScale = 0、状态 Paused（回合循环跟着停）
  → LoadScene("Pause", Single)：游戏场景卸载，暂停场景加载（GameRoot 常驻，数据不丢）
  → 暂停场景里铺满那张截图，UI 在上面摆按钮

点"返回游戏"
  → GameFlow.Resume()：timeScale / 状态恢复
  → LoadScene(点暂停时所在的场景)：GameManager 重新把场景 View 接到同一份 Session
  → PlayerController.Start 把玩家放回暂停前的站位
```

进度不丢的原因：`GameSession` / 轮次 / 住户 / 物品状态都在常驻的 `GameRoot` 上，场景只是显示层。

## 二、代码在哪

| 文件 | 职责 |
| --- | --- |
| `Assets/Scripts/Core/PauseDirector.cs` | 暂停 / 继续 / 设置 / 退出，挂在 GameRoot 上常驻；ESC 也在这里 |
| `Assets/Scripts/Core/PauseSnapshot.cs` | 现场：截图 + 回来时的场景 + 玩家站位 |
| `Assets/Scripts/Views/PauseScreen.cs` | 暂停场景里的表现：把截图铺满屏幕 + 三个按钮回调 + 键盘兜底 |
| `Assets/Scripts/Editor/YuyinPauseSceneTool.cs` | 重建暂停场景（`Tools → 余音 → 重建暂停场景`） |
| `Assets/Scenes/Pause.unity` | 暂停场景（相机 + 背景 + `UI` 空节点） |

## 三、给 UI 同学的接口

暂停场景里按钮的回调就挂这三个（`PauseScreen` 上）：

| 按钮 | 方法 |
| --- | --- |
| 返回游戏 / 继续 | `PauseScreen.OnResumeClicked()` |
| 设置 | `PauseScreen.OnSettingsClicked()` |
| 退出游戏 | `PauseScreen.OnQuitClicked()` |

也可以直接调 `PauseDirector.Instance.ResumeGame() / OpenSettings() / QuitGame()`。
游戏内的暂停按钮调 `PauseDirector.Instance.PauseGame()`。

按钮还没接的时候键盘能走通：**ESC 返回游戏、S 设置、Q 退出**（按钮接上后这几个键留不留都行）。

场景结构：`Main Camera`（正交 5.4，和游戏一屏 19.2×10.8 对齐）、`PauseScreen/Background`（背景，`sortingOrder -100`）、
`UI`（空节点，按钮和设置面板摆这里面）。

## 四、行为约定

- **暂停场景不需要 GameManager**：它没有游戏数据，只有背景和 UI。
- **站位会还原**：暂停前玩家站在哪，继续以后还站在哪（不是回到出生点）。
- **轮次不会推进**：暂停期间 `Time.timeScale = 0`，回合循环停在原地。
- **NPC 行动阶段不开放暂停**（`PauseDirector.CanPause` 要求"玩家可操作"）：
  那一段是演出，游戏场景被卸载会让正在跑的演出协程抓到空引用。
- **没截到图也不崩**：无渲染设备（`-nographics` / 批处理）或截图失败时，背景退回纯色。
- **设置场景**：调 `OpenSettings()` 时如果 Build Settings 里有 `Settings` 场景就跳过去，没有就只打一行日志（等 UI 同学接）。
