# 余音 · 物品美术接入

## 素材

物品图放在 `Assets/Art/Items/`，每个 `itemId` 有正视和侧视两张：

```
<itemId>_Front.png
<itemId>_Side.png
```

当前 9 件物品：`grandma_01`、`grandma_02`、`grandma_03`、`aunt_01`、`aunt_02`、`aunt_03`、`mother_01`、`mother_02`、`mother_03`。

衣服 `grandma_01` / `mother_01` 使用图二的衣物素材；其余物品使用图一。衣架立柱没有带入物品图，避免和场景里的衣架重复。

## 配置

`Assets/Resources/ItemArt.asset` 保存：

- `frontSprite` / `sideSprite`
- `worldHeight`
- `hangFromTop`
- `sortingOrder`

运行时选择规则：

- `PlacementSurface.Ground`：优先侧视图
- 衣架、叠放物品：正视图
- 衣物使用 `hangFromTop=true`，顶部挂在衣架锚点

`ItemView` 会自动调整 Sprite 缩放、脚底/挂点位置和 BoxCollider2D。

## 刷新

```powershell
& "<Unity>\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "E:\unity\咕咕嘎嘎" `
  -executeMethod YuyinItemArtTool.RefreshFromCommandLine `
  -logFile "E:\unity\咕咕嘎嘎\Logs\item-art.log"
```

菜单入口：`Tools → 余音 → 刷新物品美术配置`。
