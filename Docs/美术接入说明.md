# 余音 · 角色美术接入说明

对应：七天计划 第 2 / 3 / 5 天（角色定稿、接美术素材、角色规格）。

## 一、素材规格（给美术）

| 项目 | 要求 |
| --- | --- |
| 格式 | PNG-32，背景**完全透明**（alpha = 0） |
| 裁切 | 沿角色外轮廓**紧裁切**，四边留 0~4px，不要留大块空白 |
| 脚底 | **贴住图片底边**（程序按底边 = 脚下对齐） |
| 分辨率 | 建议角色高度 ≥ 700px（按 100 PPU 缩放后仍清晰），上限 2048 |
| 朝向 | 站立正面；走路翻转由程序做镜像，不需要画两版 |
| 命名 | 放进 `Assets/Art/Characters/`：`Player`、`Grandma_Sitting`、`Grandma_Walking`、`Grandma_Talking`、`Uncle_Sitting`、`Uncle_Walking`、`Uncle_Talking`、`Girl_Standing`、`Girl_Walking`、`Mother_Standing`、`Mother_Walking`（`.png`） |

导入设置（Texture Type = Sprite、Pivot = Bottom Center、PPU = 100、Alpha Is Transparency…）
由工具统一刷，不用手动改：跑一次「应用角色美术」即可。

## 二、配置在哪

`Assets/Resources/CharacterArt.asset`（`Tools → 余音 → 创建或选中角色美术配置`）。

每个角色一条：

| 字段 | 说明 |
| --- | --- |
| `sprite` | 立绘。**留空 = 继续用占位方块** |
| `height` | 立绘在世界里的高度（单位），宽度按图片比例自动算 |
| `footOffsetY` | 立绘底边相对角色 transform 的 Y 偏移，底边贴 transform 时填 0 |
| `sortingOrder` | 渲染顺序：要比门（0）大、比雨（22/24）小，默认 5 |
| `flipWithMovement` | 走路按左右方向翻转（只对主角有效） |
| `tintByWarmth` | 按暖意给整个立绘染色。占位方块用它做状态提示，**真美术要关掉** |
| `sittingArt` | 坐姿专用美术；目前老婆婆和大叔已绑定，NPC 在 `Sitting` 状态自动切换 |
| `walkingArt` | 走路专用美术；NPC 走位和走回家期间使用 |
| `talkingArt` | 交流专用美术；NPC 执行 `Talk` 行动时使用 |

当前默认值：

| 角色 | height | footOffsetY | 说明 |
| --- | ---: | ---: | --- |
| 主角 | 2.2 | -0.5 | 角色 transform y=-3.0，立绘底边落在 y=-3.5 |
| 老婆婆 | 2.0 | -1.0 | 图片：交流图兼默认站立 |
| 大叔 | 2.3 | -1.15 | 图片：交流图兼默认站立 |
| 小女孩 | 1.4 | -0.7 | 图片：站立 / 行走 |
| 母亲 | 2.1 | -1.05 | 图片：站立 / 行走，仍在门内隐藏 |

坐姿：老婆婆 `height=1.8 / footOffsetY=-0.9`，大叔 `height=2.1 / footOffsetY=-1.05`。
走路 / 交流：老婆婆 `height=2.0 / footOffsetY=-1.0`，大叔 `height=2.3 / footOffsetY=-1.15`。

## 三、怎么用

1. 把 PNG 放进 `Assets/Art/Characters/`，文件名按上面的约定；
2. `Tools → 余音 → 创建或选中角色美术配置`，把 sprite 拖进对应角色（文件名对得上会自动绑定）；
3. `Tools → 余音 → 应用角色美术（全部场景）`。

只要文件名对，第 2 步可以跳过——工具会自动按名字绑定。

只刷新图片导入设置和 CharacterArt 配置、不改场景与 Prefab：

```powershell
& "<Unity>\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "E:\unity\咕咕嘎嘎" `
  -executeMethod YuyinArtTool.BindConfigFromCommandLine `
  -logFile "E:\unity\咕咕嘎嘎\Logs\art-bind.log"
```

批处理：

```powershell
& "<Unity>\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "E:\unity\咕咕嘎嘎" `
  -executeMethod YuyinArtTool.SetupFromCommandLine `
  -logFile "E:\unity\咕咕嘎嘎\Logs\art.log"
```

换图流程：**同名覆盖 PNG → 再跑一次这个命令**。高度、脚底线、渲染顺序都会按配置重算，
不用手动调 scale，也不会因为重跑「重建基础场景」而丢（场景重建器和 NPC 工具走的是同一套）。

## 四、检查 / 预览

| 入口 | 作用 |
| --- | --- |
| `Tools → 余音 → 角色美术检查` | 打印每个角色的 sprite、世界尺寸、脚底线、渲染顺序、是否还在占位 |
| `Tools → 余音 → 渲染一张场景预览图` | 按相机取景渲染一张 PNG 到 `Logs/`，不开引擎也能看构图 |

预览渲染需要真显卡：**不能带 `-nographics`**（带了会直接报错退出）。

```powershell
& "<Unity>\Editor\Unity.exe" -projectPath "E:\unity\咕咕嘎嘎" `
  -executeMethod YuyinArtTool.RenderPreviewFromCommandLine -artScene FirstFloor
```
