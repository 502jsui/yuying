# 余音 · 音频接口说明（给 BGM 控制器 / 设置界面）

> 所有音频接口都**只**在 `Assets/Scripts/Core/AudioManager.cs` 里，取接口一律 `GameRoot.Instance.Audio`。
> 旧名字 `MusicIsPlaying` / `MusicClip` 已删除，请改用 `IsMusicPlaying` / `CurrentMusic`。

## 一、分工：只能有一个"音频出口"

| 谁 | 负责 |
| --- | --- |
| `AudioManager`（挂在 `GameRoot` 上，常驻） | **唯一**的音频出口：三条音量总线、`AudioSource` 的持有、`PlayerPrefs` 存档、音乐淡入淡出、雨声环境音、音效表播放 |
| `AudioDirector`（已在工程里） | 订阅玩法事件 → 决定"什么事件响什么音效"（不碰音量、不碰 BGM 曲目） |
| 你的 BGM 控制器 | 只决定**"什么时候播哪一首"**，播放/音量/淡入淡出全部调用 `AudioManager` |

> 不要自己再 `AddComponent<AudioSource>()`，也不要再挂第二个 `AudioListener`（主相机上已经有一个，拼接副本里会被自动关掉）。

## 二、拿接口的方式

`AudioManager` 不是场景组件，**不要去场景里找、也不要拖引用**：

```csharp
AudioManager audio = GameRoot.Instance != null ? GameRoot.Instance.Audio : null;
if (audio == null) return;   // 编辑模式 / 直接开某个场景时要判空
```

## 三、音乐接口（本次新增）

| 接口 | 说明 |
| --- | --- |
| `audio.PlayMusic(clip, loop = true)` | 立刻切到这首并播放（原有） |
| `audio.PlayMusicWithFade(clip, fadeSeconds = 0.6f, loop = true)` | **淡出旧的 + 淡入新的**；`fadeSeconds` 传 0 等于直接切 |
| `audio.PlayMusicIfDifferent(clip, loop = true, fadeSeconds = 0.6f)` | 只有不是同一首在播才换 —— **切场景用这个**，同一首不会重头播 |
| `audio.StopMusic()` | 立刻停 |
| `audio.StopMusicWithFade(fadeSeconds = 0.6f)` | 淡出后停 |
| `audio.IsMusicPlaying` | 现在有没有在播（**旧名 `MusicIsPlaying` 已删**） |
| `audio.CurrentMusic` | 现在这首是什么（**旧名 `MusicClip` 已删**） |
| `audio.SetMusicVolume(float)` | 音乐音量总线（0~1，自动存 PlayerPrefs） |

音量相关：`MasterVolume / MusicVolume / SfxVolume` 与 `SetMasterVolume / SetMusicVolume / SetSfxVolume`；三者叠加关系是 **音乐 = Master × Music**，雨声也走这条总线，音效 = Master × Sfx。

## 四、你的 BGM 控制器应该长这样

```csharp
using UnityEngine;

/// <summary>只决定"何时播哪一首"；播放器、音量、淡入淡出都交给 AudioManager。</summary>
public class BgmController : MonoBehaviour
{
    public AudioClip mainTheme;    // 平时
    public AudioClip endingTheme;  // 结局

    private AudioManager Audio
    {
        get { return GameRoot.Instance != null ? GameRoot.Instance.Audio : null; }
    }

    private void Start()
    {
        if (Audio != null) Audio.PlayMusicIfDifferent(mainTheme);
    }

    public void PlayEnding()
    {
        if (Audio != null) Audio.PlayMusicWithFade(endingTheme, 1.2f);
    }

    public void StopBgm()
    {
        if (Audio != null) Audio.StopMusicWithFade(0.8f);
    }
}
```

**不要**在这个脚本里：建 `AudioSource`、读/写 `PlayerPrefs`、改 `AudioListener.volume`、或者自己存一份音量 —— 设置界面调的音量必须直接作用到同一份真值上。

## 五、和"开局自动播音乐"的冲突怎么处理

`AudioManager.Initialize` 本来会**自动循环播放 `GameConfig.musicLoop`**（工程里默认绑的是 `Assets/Audio/Music/piano_C_slow_intermission_springspring.ogg`）。

如果你要自己接管 BGM：

1. 把 `Assets/Resources/GameConfig.asset` 上的 **`autoPlayMusicOnStart` 取消勾选**（默认是勾的）；
2. 由你的控制器在合适的时机调 `PlayMusicIfDifferent / PlayMusicWithFade`；
3. 这样就不会出现"自动播的那首"和"你播的那首"同时响。

如果保持默认（勾上），开局就有 BGM，你的控制器只负责**中途换曲**即可 —— 用 `PlayMusicIfDifferent` 也不会打断同一首。

## 六、设置界面怎么接（给做设置的同学）

```csharp
private void OnEnable()
{
    AudioManager audio = GameRoot.Instance != null ? GameRoot.Instance.Audio : null;
    if (audio == null) return;

    // 用当前值初始化滑条，且不要触发 onValueChanged
    masterSlider.SetValueWithoutNotify(audio.MasterVolume);
    musicSlider.SetValueWithoutNotify(audio.MusicVolume);
    sfxSlider.SetValueWithoutNotify(audio.SfxVolume);
}

public void OnMusicChanged(float v)
{
    if (GameRoot.Instance != null) GameRoot.Instance.Audio.SetMusicVolume(v);
}
```

滑条范围设 **0 ~ 1**（不是 0~100）；`SetMasterVolume / SetMusicVolume / SetSfxVolume` 内部会自动 clamp 并存档。

**静音开关** —— 设置界面的"静音"勾选/按钮直接调这三个，不要自己去改滑条数值：

| 接口 | 说明 |
| --- | --- |
| `audio.IsMuted` | 现在是不是静音 |
| `audio.SetMuted(bool)` | 设定静音（存 PlayerPrefs，重启保留） |
| `audio.ToggleMute()` | 切换静音，**返回切换后的状态**，方便直接写按钮回调 |

```csharp
public void OnMuteToggled(bool on)   // Toggle / 勾选框
{
    if (GameRoot.Instance != null) GameRoot.Instance.Audio.SetMuted(on);
}

// 打开界面时回显
muteToggle.SetIsOnWithoutNotify(audio.IsMuted);
```

静音只是把三路输出乘 0，**滑条上的数值不会变**，取消静音立刻按原比例恢复。
叠加关系：音乐 = Master × Music，雨声 = Master × Music × 雨声强度，音效 = Master × Sfx；静音时三者再 × 0。

## 八、验收（改完自测）

1. 进游戏有 BGM，切一楼 / 后院 **不重头播**、不叠播
2. 设置界面拖"音乐"滑条 → BGM 音量实时变化，重启游戏后保持
3. 场景里只有一个 `AudioListener`
4. Console 里没有 "There are 2 audio listeners in the scene" 之类的警告
